# backups/

Ablagestruktur für lokale Backups. Die tatsächlichen Archive werden
**nicht** versioniert (siehe `.gitignore`) — dieses Verzeichnis
dokumentiert nur, wo sie erwartet werden.

Die produktive Backup-Ablage ist für `/var/backups/companion/` geplant
(siehe [ARCHITECTURE.md](../ARCHITECTURE.md)); dieses Verzeichnis dient
repo-nahen Zwecken, z. B. Backups der PixelHermes-Konfiguration selbst.

Aktuell leer, keine Backup-Jobs eingerichtet.
