# systemd/

Geplante systemd-Unit-Dateien für PixelHermes-Dienste. Es gibt aktuell
noch keine Dienste — daher noch keine Units.

Sobald ein Dienst eingeführt wird, kommt seine Unit-Datei versioniert
hierher, bevor sie auf dem System aktiviert wird (Infrastructure as
Code: die Unit-Datei im Repo ist die Quelle der Wahrheit).

Aktuell leer.
